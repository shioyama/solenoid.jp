# SOLENOID

This is the website for SOLENOID, a cafe and event space located in the Nijukken-zaka area of western Hakodate, Japan.

## About

SOLENOID is run by Canadian programmer Chris Salzberg and operates as:
- A regular office/workspace
- A cafe open one evening per week, and occasionally at other times
- In the future, an event space (planned)

The name "SOLENOID" has three meanings:
1. A 2015 novel by Romanian writer Mircea Cărtărescu (winner of the 2024 International Dublin Literary Award)
2. The valve mechanism in modern espresso machines
3. A physics term for a coil that generates a magnetic field when current flows through it

## Website Purpose

The website provides information about:
- The space and atmosphere
- Opening hours and calendar
- Access information and directions
- Background about the name and concept

## Multilingual Structure

The site is bilingual (Japanese/English):
- Homepage at `/` is language-neutral (just logo)
- Clicking from homepage auto-detects browser language and redirects to:
  - `/ja/about` for Japanese
  - `/en/about` for English
- All content pages are organized by language:
  - Japanese: `/ja/about`, `/ja/space`, `/ja/calendar`, `/ja/access`
  - English: `/en/about`, `/en/space`, `/en/calendar`, `/en/access`
- Language switcher in navigation allows toggling between languages
- Navigation menu adapts based on current page language
